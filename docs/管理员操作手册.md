# 管理员操作手册

## 1. 登录后台

1. 打开 `https://<你的Pages域名>/admin.html`；
2. 输入部署 Worker 时设置的 `ADMIN_TOKEN`；
3. 密钥只存在当前浏览器会话（sessionStorage），关闭页面后清除；公共电脑使用后请点「退出」。

## 2. 发布普通公告

1. 进入「公告管理」；
2. 填写标题、标签（可选）、作者（可选）、正文；
3. 需要置顶就勾选「置顶展示」；
4. 点「发布公告」，首页公告列表会实时出现该公告。

- 公告长期留存，可在列表中删除；
- 正文按纯文本展示，换行保留；不支持 HTML 排版，避免 XSS。

## 3. 生成阅后即焚通知

1. 进入「阅后即焚」；
2. 填写标题、密级、正文；
3. 设置链接有效期（小时，最长 720 小时）；
4. 点「生成一次性链接」，复制链接线下发给指定人员；
5. 员工打开链接 → 阅读规则 → 点击「我已确认，开始查看」→ 后端返回内容并**立即从 KV 删除**；
6. 链接再次打开提示「内容不存在或已被销毁」；超过有效期未打开也会自动失效。

### 查阅端的风控行为

员工页面开启后，以下行为会触发黑屏锁定：

- 截图按键、macOS 截图组合键；
- 切窗、切到后台、打开截图 / 录屏工具导致失焦；
- 打开开发者工具；
- 右键、复制、拖拽选中文本；
- 打印、画中画、页面被嵌入。

触发后页面清空内容并全屏黑屏，同时后端记录一条审计日志（IP、UA、触发原因、时间）。

## 4. 生成卡密

1. 进入「卡密管理」；
2. 填写资料名称、选择类型：
   - **文本内容**：核验通过后直接展示一段文字；
   - **外部链接**：核验通过后给出一个可点击的链接；
   - **R2 文件**：从绑定的 R2 桶下载指定对象（需要先绑定 R2）；
3. 设置可用次数（默认 1 次）、过期时间（可选）、备注（仅后台可见）；
4. 点「生成卡密」，立即复制卡密并线下发放。

> 后台**不回显完整卡密**。卡密以 SHA-256 哈希形式存储在 KV 中；列表只展示 hash 前 10 位用于定位。卡密一旦生成，只能停用、不能查看原文。

### 停用卡密

在卡密列表找到对应记录，点「停用」。停用后该卡密立即失效，已使用的记录保留。

## 5. 文件类卡密（R2）

1. 在 Cloudflare R2 创建桶，在 Worker 绑定为 `FILES`；
2. 把文件上传到桶，记下对象键（如 `reports/2026/q3-summary.pdf`）；
3. 生成卡密时类型选「R2 文件」，填写对象键和下载文件名；
4. 员工核验通过后拿到一个 10 分钟内有效的一次性下载链接，下载完成即失效。

## 6. 审计与排障

- **风控上报记录**：保存在 KV 中，key 前缀 `breach:`，保留 90 天。需要在后台查看时，可在 Worker 后台直接读 KV，或后续在管理后台增加导出接口；
- **访问日志**：`npx wrangler tail` 实时查看 Worker 请求；
- **跨域报错**：检查 `ALLOWED_ORIGINS` 是否包含 Pages 域名（注意协议和端口完全一致）；
- **卡密提示「验证过于频繁」**：同一 IP 1 小时内失败 12 次会被限流，稍后重试；
- **焚毁链接提示「不存在或已被销毁」**：说明已被查阅过、已过期，或 token 复制不完整。

## 7. 日常注意事项

- 不要把 `ADMIN_TOKEN` 发给普通员工；不要把管理入口链接公开转发；
- 卡密发放尽量一对一下发，不要贴在公开群聊；
- 高密文件优先使用「单次卡密 + 短有效期 + R2 一次性下载链接」；
- 定期在卡密列表清理已停用、已过期、已用完的记录；
- 如怀疑泄露：立即停用对应卡密、作废焚毁链接（删除 KV 中对应 `burn:` 记录），并在风控记录里核查访问来源 IP。
